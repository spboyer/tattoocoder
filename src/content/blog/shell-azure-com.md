Checkout [http://shell.azure.com](http://shell.azure.com)! A dedicated experience in a browser. No installation of the Azure CLI and all you need is your Azure account credentials to get going.

![shell-azure](/content/images/imported/shell-azure-com-image-0.png)

![azure-tmux](/content/images/imported/shell-azure-com-image-1.png)
