Just a quick update on what the **yo aspnet** team has been working on.

Bootstrap (aka Twitter Bootstrap) is the very well known UI layout engine and has been the standard for the ASP.NET generator. However, there was a contributor - **[Josh Williams](https://github.com/jackjwilliams)** pitching the idea of using [Semantic UI](http://semantic-ui.com/) ([http://semantic-ui.com/](http://semantic-ui.com/)) as an alternative.

After some conversation with other members of the team, we decided that **choice** would prevail and offer the following options.

```
$ yo aspnet

     _-----_
    |       |    .--------------------------.
    |--(o)--|    |      Welcome to the      |
   `---------´   |  marvelous ASP.NET Core |
    ( _´U`_ )    |      1.0 generator!      |
    /___A___\    '--------------------------'
     |  ~  |
   __'.___.'__
 ´   `  |° ´ Y `

? What type of application do you want to create? Web Application
? Which UI framework would you like to use? (Use arrow keys)
❯ Bootstrap (3.3.5)
  Semantic UI (2.1.8)
  Material Design Lite (1.1.2)
```
