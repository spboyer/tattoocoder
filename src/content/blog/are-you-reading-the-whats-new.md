Did you know that every month, the docs team at Microsoft has a post for [what's new in the .NET documentation](https://docs.microsoft.com/dotnet/whats-new/?WT.mc_id=blog-docs-shboyer)?

For each month there are new articles, updates to existing docs, and kudos for the [community contributors](https://docs.microsoft.com/en-us/dotnet/whats-new/dotnet-2020-01#community-contributors).

> It's super easy to get involved in contributing to the docs for the related technologies you are invested or interested in.  See the [Microsoft docs contributors guide](https://docs.microsoft.com/contribute) or simply click the "Edit" link at the top of any doc to get started, they are all open source!

Here are some of the highlights for [last month](https://docs.microsoft.com/dotnet/whats-new/dotnet-2020-01?WT.mc_id=blog-docs-shboyer) .NET Docs

The [**Architecting Cloud-Native Apps for Azure architecture guide e-book**](https://docs.microsoft.com/dotnet/architecture/cloud-native/?WT.mc_id=blog-docs-shboyer) added some new sections -

-   [Caching in a cloud native app](https://docs.microsoft.com/dotnet/architecture/cloud-native/azure-caching?WT.mc_id=blog-docs-shboyer)
-   [Database per microservice](https://docs.microsoft.com/dotnet/architecture/cloud-native/database-per-microservice?WT.mc_id=blog-docs-shboyer)
-   [Elasticsearch in in a cloud native app](https://docs.microsoft.com/dotnet/architecture/cloud-native/elastic-search-in-azure?WT.mc_id=blog-docs-shboyer)

**[C# language](https://docs.microsoft.com/dotnet/csharp/?WT.mc_id=blog-docs-shboyer)** revised the [Value types](https://docs.microsoft.com/dotnet/csharp/language-reference/builtin-types/value-types?WT.mc_id=blog-docs-shboyer) and [added new <inheritdoc> xml documentation](https://docs.microsoft.com/dotnet/csharp/programming-guide/xmldoc/inheritdoc?WT.mc_id=blog-docs-shboyer)

**.NET** added a great new article in the **[.NET Guide](https://docs.microsoft.com/dotnet/standard/?WT.mc_id=blog-docs-shboyer)** on [How to migrate from Newtonsoft.Json to System.Text.Json](https://docs.microsoft.com/dotnet/standard/serialization/system-text-json-migrate-from-newtonsoft-how-to?WT.mc_id=blog-docs-shboyer)

Other areas of the docs are also adding similar related what's new pages too. Check out **[ASP.NET Core docs updates](https://docs.microsoft.com/aspnet/core/whats-new/?view=aspnetcore-3.1&WT.mc_id=blog-docs-shboyer)** and **[Xamarin updates](https://docs.microsoft.com/xamarin/whats-new/?WT.mc_id=blog-docs-shboyer)** too!

The docs continue to grow and evolve. Check in often on these pages to keep up to date with the latest content.
