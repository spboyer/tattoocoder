It's a new year and sure to be on your list, as well as mine, is learning. Here is a quick list of some .NET learning resources for you to check off that resolution for 2020.

## .NET 101 Videos - [dot.net/videos](https://dotnet.microsoft.com/learn/videos?WT.mc_id=learn-blog-shboyer)

![.NET 101 Videos](/content/images/imported/so-many-ways-to-learn-net-in-2020-image-0.png)

In September of 2019, many members if the .NET team created over 100 videos for topics including C# 101, .NET, desktop apps, ASP.NET web apps, learning containers and Docker. More have been added recently including a whole series around creating and managing NuGet packages.

All of the videos are available on [YouTube](https://www.youtube.com/channel/UCvtT19MZW8dq5Wwfu6B0oxw) or [Channel 9](https://channel9.msdn.com/Search?term=101&WT.mc_id=learn-blog-shboyer).

## Microsoft Learn

[Microsoft Learn](https://docs.microsoft.com/learn/?WT.mc_id=learn-blog-shboyer) allows you to master core concepts at your speed. Take 15 minutes to complete a module or start a whole learning path  over a course of an hour or multiple hours on your schedule.

#### C# Modules

![C# Learning modules](/content/images/imported/so-many-ways-to-learn-net-in-2020-image-1.png)

[Over 20 Modules](https://docs.microsoft.com/learn/browse/?term=c%23&WT.mc_id=learn-blog-shboyer) on C# available.

#### ASP.NET / .NET Core Modules

![asp.net core modules](/content/images/imported/so-many-ways-to-learn-net-in-2020-image-2.png)

[Create a web API with ASP.NET Core](https://docs.microsoft.com/learn/modules/build-web-api-net-core/?WT.mc_id=learn-blog-shboyer) - Create a RESTful service with ASP.NET Core that supports Create, Read, Update, Delete (CRUD) operations.

[Create a web UI with ASP.NET Core](https://docs.microsoft.com/learn/modules/create-razor-pages-aspnet-core/?WT.mc_id=learn-blog-shboyer) - ASP.NET Core supports creating webpages using a built-in templating engine called Razor. In this module, you'll learn how to create webpages using Razor with ASP.NET Core.

[Secure an ASP.NET Core web app with the Identity framework](https://docs.microsoft.com/learn/modules/secure-aspnet-core-identity/?WT.mc_id=learn-blog-shboyer) - Add authentication and authorization to an ASP.NET Core web app using the Identity framework.

[Persist and retrieve relational data with Entity Framework Core](https://docs.microsoft.com/learn/modules/persist-data-ef-core/?WT.mc_id=learn-blog-shboyer) - Query and manage relational data in a .NET Core app with an Object-Relational Mapper.

## Others

-   [On.NET Show](https://channel9.msdn.com/Shows/On-NET?WT.mc_id=learn-blog-shboyer) - Channel 9 show hosted by Cecil Phillip [cecilphillip](https://twitter.com/cecilphillip), Rich Lander [@runfaster2000](https://twitter.com/runfaster2000) and other guest hosts. Great content where they look at the APIs, the tooling, and some of the interesting projects being created in the .NET ecosystem.
-   [Azure Friday](https://channel9.msdn.com/Shows/Azure-Friday?WT.mc_id=learn-blog-shboyer) - Join Scott Hanselman, Donovan Brown, or Lara Rubbelke as they host the engineers who build Azure, demo it, answer questions, and share insights.
